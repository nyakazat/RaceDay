# RaceDay Event Management System

RaceDay is a full-stack event management system for South African running, walking and cycling events.

## Roles

### Organiser
Can create, edit and delete events, manage categories, view enrolments and capture participant results.

### Participant
Can register, browse events, enrol in event categories and view personal results.
